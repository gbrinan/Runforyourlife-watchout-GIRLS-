## 5-Question Reboot Check
| 질문 | 답 |
|---|---|
| 1. 나는 어디에 있나? | 3단계(전환 설계) 진행 중. 분석(2단계) 완료 |
| 2. 어디로 가나? | 목표 게임 확정 → 4-1 상태/세이브 구현부터 |
| 3. 목표는? | CTLC2의 좋은 구조는 살리고 부채(D1~D10)는 피한 코드 구조로 우리 게임을 만든다 |
| 4. 무엇을 배웠나? | 코어 로직 28벌 복제, INI 전역 상태, 데이터 하드코딩이 CTLC2의 3대 부채. 입력·사운드 중앙화와 명명 규칙은 계승할 가치 |
| 5. 무엇을 했나? | 세션 1 기록 참조. 산출물은 docs/ctlc2/, plan/ctlc2/ |
