# EXIT와 랜덤 상호작용 검증

## 인수 결과

- 방5~8개, 너비·깊이8~14m. 시드에 따른 추가 복도. 명시 seed 재현, 새 던전 생성은 새 seed.
- 가챠/스위치가 나타나는 방, 장치 수, 벽면 위치·방향, 초기 점등 상태 변화. 역할은 일관되며 R로 작동.
- EXIT 표지와 열린 통로 생성. 문턱1.8m 밖으로 걸어 나가면 클리어. 열쇠·스위치·적 처치 조건 없음.
- 클리어 후 시간/추격/피해 업데이트와 오디오 정지. 소요시간 안내, 새 던전 재시작.

## 자동 검사

123/123 테스트, 타입검사 통과. 100시드에서 모든 장치 접근점과 EXIT 바깥까지 경로 존재. 방 수·장치 수 다양성, 네 방향 배치와 켜짐/꺼짐 상태 확인. 출구를 향해 넘을 때만 클리어, 옆/역방향 진입은 불허.

빌드 전체 gzip155.11KB,300KB예산 이내. 기존vendor 원본500KB 안내 유지.

## 실제 표면

실제 Chrome, 키보드/마우스 이동·R 입력. 테스트시계로 프레임을 재현했으며 플레이어/적/클리어 상태는 주입하지 않음. 생성기에서 경로를 계산해 실제 입력으로 이동.

- exit-browser-results.json: EXIT 진입 전 오버레이 없음 →26초 탈출 성공 →5초 후 시간표시 동일 →새 seed로 재시작. pageerror0.
- random-browser-results.json: 다른 시드에서 가챠12초 활성화, 조명 꺼짐/켜짐 확인. pageerror0.
- 최종13장: exit-start-1280, exit-map-a, exit-door, exit-clear, exit-restart, exit-start-375, exit-start-768, random-start, random-map-b, random-gacha, random-switch, random-switch-on, random-pause.
-375px 소개문 의미단위 줄바꿈을4개 짧은 문장으로 수정, 전체13장 최종빌드 재캡처.

## 남은 범위

현재는 던전 탈출 프로토타입. 별도 야외 엔딩/문 파괴/아이템은 없음. 스위치 결과를 무작위로 뒤집는 대신 배치와 초기 상태를 바꿔 조작 결과는 예측 가능하게 유지.

## 최종 독립 검토

exit_final_functional: PASS, 차단사항 없음. exit_final_visual: PASS, 차단사항 없음. 두 검토자 모두 최종13장·실행JSON·소스 확인. 이전 모바일 줄바꿈 발견은 수정 후 새 검토자가 재검증했다.
