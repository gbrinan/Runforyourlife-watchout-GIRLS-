# 학교 지하실 미장센 QA

범위: 가상의 서울 여고 지하실, 여고생 소환의식으로 나타난 유니콘, 새 환경 재질·비품·초기 카메라·시작 문구. 기존 세 종 퍼즐은 유지한다. 단일 열쇠·함정·TV 이브는 후속 기획이다.

최종 제품 빌드: `main-DlTKdITu.js`, `heels-7KeuTbuU.js`, `main-R1rfrIad.css`.

- 타입검사, 17파일 133테스트, 프로덕션 빌드 통과. 기존 Three.js 500kB 원본 청크 경고는 남음.
- `school-scene.cjs`가 실제 Chrome에서 시작·제자리 Q 회전·W 이동·아래 보기·정지를 실행했다. 게임 상태를 주입하지 않고 AudioContext 리스너를 관찰했다.
- `school-results.json`: 오류 0, 회전 중 이동 거리 0m, 이동 1.5498002m, 정지 시 오디오 suspended 확인. 세 화면 너비 모두 수평 넘침 없음.
- 최종 9장: 1280×900 intro/play/side/ritual/paused, 768×900 intro/play, 375×900 intro/play. 모든 캡처는 최종 제품 수정과 빌드 이후 새로 생성했다. 주 에이전트가 모두 직접 열어 확인했다.
- 첫 화면의 과도한 균일 조명과 배관에 가린 표지를 발견해 광량·표지 높이·초기 시선·정적 그림자를 수정했다. 첫 캡처는 최종 판정에 사용하지 않는다.
- 정확한 이미지 복제 요청이 아니므로 픽셀 일치 점수는 판정에 사용하지 않는다. 새로운 장면은 실제 Three.js 메시·재질이며 표지에만 CanvasTexture를 쓴다.
- 사진 수준 사실주의, 실제 노트북 60fps, 사람의 공포감 평가, 새 엔딩 여정 전체를 이번 검사로 주장하지 않는다.

첫 독립 검토: school_scene_integrity PASS, school_scene_visual REVISE. 칠판·공책 가독성과 실내화 구도 지적을 수용해 문구 단축, 글꼴 크기·표지 대비 확대, 시작 방향에 맞춘 소품 배치와 입체 실내화로 수정했다. 수정 후 타입검사·133테스트·빌드를 다시 통과했다. 최종 캡처와 두 검토를 갱신 중이다.
