# 공포 퍼즐과 캔디마운틴 QA

## 검증 범위
- WASD 이동, Q/E 제자리 회전, Space 점프/착지, F 공격과 H 울음 안내.
- 접근 가능한 세 종과 비문, 오답 초기화/소음, 순서 정답으로 봉인 해제.
- 봉인된 EXIT 점프 통과 차단, 정답 후 실제 문턱 통과 시 3D 캔디마운틴.
- 엔딩 시간 정지, 새 던전 재시작, 375/768/1280 화면.

## 실행 증거
- 타입검사 및 프로덕션 빌드 성공, 130/130 테스트 성공.
- `horror-ending.cjs`: 실제 Chrome 키/마우스 입력. 게임 상태 주입 없이 경로 이동.
- `horror-results.json`: pageerror 없음, 오답/정답/엔딩/정지/재시작/봉인 차단 확인.
- 캡처 23개: start 3, jump 3, control 6, clue, wrong, puzzle 3, solved, exit, ending 3, locked.
- 이미지 참조를 복제하는 작업이 아니므로 픽셀 일치율은 적용하지 않음.

## 독립 검토
- `horror_verified_functional`: PASS. 최신 23장과 소스, 실제 입력 기록 전체 확인. 기능 및 증거 차단 사항 없음.
- `horror_verified_visual`: PASS. 최신 23장 전체 확인. 좁은 화면의 단서 두 줄과 안쪽을 향한 봉인 표지 수정 확인. 한국어/레이아웃/합성 차단 사항 없음.
- 첫 검토의 표지 반전과 단서 고아행을 수정한 뒤 빌드 및 전체 실제 입력 캡처를 다시 생성했다. 최종 빌드 `main-D34y-3nk.js`.
- 실제 메시/DOM 구성, 입력/퍼즐/출구 흐름, 리사이즈, 투명도, 시각적 의도, 한국어 표시 모두 good. 미해결 차단 사항 없음.

## 제한
- 기존 큰 Three.js 번들 경고 유지.
- 공포감과 음향의 주관적 청취 평가는 하지 않음.
- QA의 frozen 값은 엔딩 설명 불변을 검사한다. 추격/피해/시간 정지는 엔딩에서 게임 tick을 중단하는 소스 검토로 함께 확인했다.
