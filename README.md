# 캔디마운틴까지 (Unicorn Horror)

외부 에셋 없이 지형·캐릭터·사운드를 생성하는 1인칭 유니콘 호러.
현재는 **서울의 가상 은목여자고등학교 지하실에서 소환된 유니콘의 탈출 프로토타입**이다. 여고생들이 야자 후 벌인 소환의식은 성공했고, 학생들은 사라졌다. 추격자들은 의식에 딸려온 성인 모습의 존재다.
[Vercel에서 바로 플레이](https://runforyourlife-watchout-girls.vercel.app/)
단기 재설계 정본: [GDD v0.4](docs/GDD-v0.4.md) (구현 전). 기존 장기 구상: [GDD v0.3](docs/GDD.md). 작업 상태: [task_plan.md](task_plan.md).

## 현재 플레이 공간

- 방 5~8개와 폭 3m 복도, 연속된 3m 천장. 녹색 하부 도장과 누수 자국, 테라조 바닥, 형광등·노출 배관·철제 비품장·학교 표지.
- 매판 새 시드로 방 위치·크기·복도 연결과 낡은 표면을 생성한다. 명시한 시드에서는 같은 맵을 재현한다. 학교 재질·표지·비품과 오디오는 런타임 생성한다.
- 시작 방의 칠판은 “유니콘 소환 실험”을 적고, 발밑에는 분필 원·초·공책·실내화가 남아 있다. 첫 시선은 칠판을 향한다. 시작 조명은 처음에 켜지고 이후 스위치로 제어할 수 있다. 차가운 형광등과 따뜻한 초, 시작 방의 정적 그림자를 사용한다.
- 첫 25초에는 피해를 주는 적이 없다. 대신 방에서 거울·출석부·사물함 쪽지·가챠를 만지는 여인과 말 영상을 보는 이브를 먼저 목격할 수 있다. 목격한 인물은 그 자리에서 얼굴을 돌리고, 만나지 못한 인물만 25/45/70초 뒤 플레이어 뒤쪽 4.5~6.5m에서 등장한다. 최대 세 명과 경로·벽 규칙은 유지된다.
- 발각 뒤 1.5초 동안 고개를 돌리고 숨을 들이쉰 뒤 추격한다. 잡기 직전에는 두 팔을 벌리고 0.8초 동안 멈춰 옆으로 피할 수 있다. 등장 자체는 접촉 피해를 주지 않는다.
- 힐·발굽·울음은 공간 오디오와 짧은 잔향으로 들린다. 기습 시 방향성 하이힐과 여성 음색의 숨소리가 먼저 들리고, 왼쪽·오른쪽에 맞춰 붉은 시야와 자막 위치가 바뀐다.
- 스태미너, 발자국, H 울음, F 들이받기, Space 점프, 3회 피해·사망·새 시드 재시작.

## 캐릭터와 집착녀

시작/정지 화면의 **등장인물 · 약점 보기**에서 실제 모델과 설명을 볼 수 있다.

| 캐릭터 | 외형 | 행동 |
|---|---|---|
| 세라 | 핑크 단발 · 글래머 | 2.4m/s 균형형 추격 |
| 유나 | 작은 얼굴·흑발 장발 · 슬렌더 | 2.9m/s 끈질긴 추격 |
| 린 | 은발 숏컷 · 슬렌더 | 2.15m/s 느린 수색형 |
| 로제 | 작은 얼굴·핑크 장발 · 글래머 | 3.2m/s, 넓은 잡기 범위 |
| 이브 | 작은 얼굴·백금 장발 · 붉은 드레스 | 3.5m/s로 끝까지 추격 |

세라는 깨진 거울 앞에서 외모를 확인하고, 유나는 빈 교실의 출석을 부르며, 린은 유니콘에게 쪽지를 남기고, 로제는 가챠의 마지막 상품을 기다린다. 이브는 TV의 말 영상을 보다가 실제 유니콘을 알아본다. 각 장면은 고유 소품·손짓·대사로 먼저 인물을 알리고 이후 같은 모델이 추격한다.

이브는 일반 공격으로 0.45초만 멈춘다. 시작 방과 네 번째 방의 **청록색 봉인진** 안으로 이브를 유인한 뒤, 적을 정면으로 바라보고 F로 들이받아야 봉인된다. 플레이어만 진 안에 있는 것은 부족하다. 봉인되면 모델·공격·추적·발소리가 사라지고 이번 판에서 돌아오지 않는다. 재시작하면 다시 등장한다.

추격 속도와 잡기 예고는 인물마다 다르며 이브가 가장 빠르고 강하다. 추격 중 4초 간격으로 공간 합성 괴성을 낸다. 뒤쪽 12m 이내에서 벽에 가리지 않고 추격하면 전면에 붉은 경고와 “뒤에서 쫓아온다” 안내가 뜬다.

무작위 방·벽면에 배치된 **소리 가챠**에 접근해 R을 누르면 12초 동안 40m 안의 적을 유인한다. 이브도 잠시 유인되지만 효과가 끝나면 추격을 재개한다. 재사용 대기는 작동부터 25초다. **조명 스위치**는 방의 벽등을 켜고 끄며, 어두운 방에서 일반 적의 시야 범위를 18m에서 7m로 줄인다. 이브의 집착 추적은 유지된다.

## 탈출과 랜덤 장치

시작 방의 **세 종의 비문** 가까이에서 R로 단서를 기록한다. 첫 번째와 마지막 종을 알려주는 단서에서 순서를 추론한 뒤 달·눈·가시의 종을 R로 울린다. 순서는 매판 달라진다. 오답은 진행을 초기화하고 60m 소음으로 적을 유인한다. 정답을 완성하면 EXIT의 붉은 봉인이 사라진다.

**봉인을 풀고 EXIT 문턱을 통과하면 무지개빛 캔디마운틴 엔딩**으로 전환된다. 실제 3D 무지개 산맥·사탕나무·무지개 길이 나타나며 시간·추격·피해·게임 오디오가 멈춘다. “새 던전 시작”으로 다시 플레이한다. 모든 생성 맵에는 종·단서·EXIT로 향하는 접근 가능한 경로가 있다.

방 수·가로세로 비율·연결 복도, 가챠와 스위치의 개수·방·벽면 방향·위치가 시드마다 달라진다. 스위치가 있는 방은 처음부터 어두울 수도 있다. 장치의 역할은 항상 같으며, R을 눌러 켜기/끄기 또는 유인할 수 있다. 시작/일시정지 화면의 “새 던전 생성”은 명시된 시드도 버리고 새 맵을 만든다.

## 실행

```bash
npm ci
npm run dev -- --host 127.0.0.1
```

- `http://localhost:5173/` — 던전. 버튼 또는 Enter로 시작.
- `http://localhost:5173/?seed=hello` — 같은 방 구조를 재현.
- `http://localhost:5173/m1.html` — 기존 M-1 파스텔 초원·합성음 실험실.

| 입력 | 행동 |
|---|---|
| W / S | 전진 / 후진, 키를 놓으면 즉시 정지 |
| A / D | 왼쪽 / 오른쪽으로 이동 |
| Q / E | 이동 없이 시점을 왼쪽 / 오른쪽으로 회전 |
| Shift / Ctrl 유지 | 달리기 / 살금살금 이동 |
| 기본 이동 | 속보 3m/s, 대각선 속도 동일 |
| 마우스 | 좌우·상하 시선 (포인터 락 거부 시 캔버스 위 마우스 이동) |
| ← → / ↑ ↓ | 좌우 / 상하 시선 |
| R | 가까운 비문 / 종 / 가챠 / 조명 스위치 상호작용 |
| H | 히힝, 60m 소음 |
| Space | 점프. 공중 재점프 불가, 착지 시 18m 소음, 벽 충돌 유지 |
| F | 정면 2m 들이받기, 25m 소음. 동일 적에게 2번만 유효 |
| Esc / Enter | 일시정지·설정 / 시작·재개 |

돌바닥은 서행도 6m 소음을 낸다. 모퉁이를 돌아 시야를 끊을 수 있지만 발자국은 30초간 남는다. 질주는 초당 스태미너 12, 구보는 3을 소모하며 속보 이하에서 초당 8 회복한다. 소진 시 20까지 회복할 때까지 속보로 제한된다. 갈기를 잃으면 질주 소모가 두 배다.
시작/정지 화면에서 마우스 감도를 조절할 수 있다. 화면 흔들림은 기본 꺼짐이다. 이동·회전 키는 물리키로 처리하므로 한글 입력 상태에서도 작동한다. 달리기 중에도 시선을 자유롭게 돌릴 수 있다. 포인터 락 상태에서는 왼쪽 클릭으로도 공격한다. 키보드·마우스용이며 터치 조작 미지원. 이어폰 권장.

## Blender 던전 키트

고딕 출입구 모듈은 `blender/dungeon-kit.blend`가 원본이고 `public/assets/dungeon-kit.glb`가 게임용 자산이다. Blender 5.2 이상에서 아래 명령으로 두 파일을 다시 만들 수 있다.

```powershell
blender --background --python tools/blender/build_dungeon_kit.py
```

고딕 키트는 이전 던전 원본으로 보존한다. 현재 학교 장면에서는 고딕 GLB를 불러오지 않으며 학교 비품과 건축은 코드로 생성한다. 방·복도·충돌·EXIT 경로는 기존 런타임 생성기가 담당한다.
